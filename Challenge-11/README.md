Challenge Objective 
A university wants to reduce water wastage across its campus. Develop a menu-driven C program that analyses seven days
of water-consumption readings from five campus zones, detects unusual usage, identifies zones that exceed their daily	 
targets, and recommends where conservation efforts should begin. Your solution must combine a two-dimensional array,	 
user-defined functions, nested loops, conditional statements, and meaningful pointer operations.

Algorithm – WATERWISE

1. Start.
2. Declare arrays to store water readings for 5 zones over 7 days and their daily targets.
3. Input and validate the daily targets and water readings.
4. Display the main menu.
5. If option 1 is selected, display the water consumption data.
6. If option 2 is selected, calculate the weekly total, average, peak usage, excess consumption, spikes and unique alert days. Display the audit report.
7. If option 3 is selected, rank the zones according to excess consumption, giving equal ranks to tied zones.
8. If option 4 is selected, display suitable water conservation recommendations.
9. If the audit report has not been generated, display a warning before options 3 and 4.
10. Repeat the menu until the user selects Exit.
11. Stop.
