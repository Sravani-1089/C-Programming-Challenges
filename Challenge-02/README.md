Algorithm
1. Start
2. Declare variables for distance, mileage, fuel price, fuel required, and total fuel cost.
3. Read the total distance to be travelled in kilometres.
4. Read the vehicle mileage in kilometres per litre.
5. Read the fuel price per litre.
6. Calculate fuel required:
      Fuel Required = Distance / Mileage
7. Calculate total fuel cost:
      Total Fuel Cost = Fuel Required × Fuel Price
8. Display the fuel required.
9. Display the total fuel cost.
10. Stop
