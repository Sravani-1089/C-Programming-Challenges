Algorithm

1. Start.
2. initialize all counts and totals to zero.
3. Read the expense amount until the user enters 0.
4. If the amount is negative, display “Invalid expense!”.
5. If the amount is positive, classify it as Small, Medium, or Large and update the counts and totals.
6. Display all counts, totals, and average.
7. If there are no valid expenses, display no valid expenses entered.
8. stop.
