Challenge Objective
Your university is organising a technical event in an auditorium with 5 rows and 8 seats in each row. Develop a menu-driven C program called
SEATSMART to manage seat reservations. The program must allow users to view seats, book or cancel an individual seat, reserve consecutive seats for a
group, and view an occupancy report. You must use a two-dimensional array and separate user-defined functions for the major operations.

Algorithm: SEATSMART

1. Start the program.
2. Create a seating array of 5 rows and 8 columns.
3. Initialize all 40 seats as available (0).
4. Display the menu with six options.
5. Read the user's choice.
6. If choice is 1, display all seats.
7. If choice is 2, book a valid available seat.
8. If choice is 3, cancel a valid booked seat.
9. If choice is 4, book the first available consecutive seats for the group.
10. If choice is 5, display booked seats, available seats, occupancy percentage and busiest row(s).
11. If choice is 6, display the closing message and exit.
12. Repeat the menu until the user exits.
13. Stop the program.
