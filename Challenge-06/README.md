Challenge Objective:
A smart-campus activity monitor records the number of visits over several time slots. Your task is to write a C program that studies the
sequence, finds meaningful patterns, and then rotates the data for a cyclic report. The important part is to plan the logic before coding
and to handle unusual cases correctly.

Algorithm:

1. Start.
2. Read N and check that it is between 5 and 12.
3. Read N array elements and check that each is between 0 and 1000.
4. Display the original array.
5. Calculate and display the sum, average, minimum and maximum.
6. Find and display the second-largest distinct value, if it exists.
7. Count and display the local peaks.
8. Find and display the longest increasing contiguous run.
9. Read K and rotate the array according to its sign and magnitude.
10. Display the rotated array.
11. Read the last two digits R of the registration number.
12. Calculate D = (R % 9) + 1.
13. Count and display the values divisible by D.
14. Stop.
